# ClipBridge Bluetooth：简单使用说明

## 首次使用

1. 解压 Windows 发布包，运行 `ClipBridgeBLE.exe`，右击右下角托盘 → 显示状态 → 显示密钥。
2. iPad 安装 Swift Playgrounds，解压 iPad 发布包，打开 `ClipBridgeBLE.swiftpm` 并运行。
3. 输入电脑密钥，允许蓝牙，点击“连接 Dell”（界面名称，不限制电脑品牌）。
4. 前台和后台分别测试新图、新文字的实际粘贴，确认你的设备兼容。文字功能须两端都更新至 v0.4.0-beta。

希望桌面安装及 Windows 登录自启动：在 Windows ZIP 解压目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-Desktop.ps1
```

不需要自启动时加 `-NoStartup`。直接运行 EXE 是便携使用，不会自动注册启动项。

## 平时使用

电脑 `Win+Shift+S` 截图 → 等待蓝牙传输 → iPad Goodnotes 长按“粘贴”。

电脑选中文字 `Ctrl+C` → 等待蓝牙传输 → iPad 在备忘录编辑区，或 Goodnotes 文本框编辑状态中粘贴。支持中文、英文、换行、Emoji；只同步纯文本，不保留字体排版。只复制，不会自动替你在 Goodnotes 插入。

保持两端蓝牙开启，不需要同一 Wi-Fi 或热点。不要划掉 iPad 接收程序；重启或被系统终止后，重新打开、运行并连接。电脑上不要同时运行命令行和托盘版。

## 托盘操作

- **显示状态**：查看连接、最近内容和回执耗时；不显示文字正文。回执不代表粘贴已经成功。
- **暂停剪贴板捕获**：暂不发送新图片或文字；暂停会被保存。恢复后只处理新内容，已开始的传输可能完成。
- **同步文字**：默认勾选；取消后只同步图片。开关状态会保存。
- **画质 / 发送模式**：默认均衡＋快速队列；原图较慢，逐包兼容用于连接或分片问题。
- **重新发送最新内容**：重发本次运行内存中保留的最后一张图或一段文字。
- **重启蓝牙发送端**：仅重建本程序服务，iPad 可能需要重新连接。
- **开机自启动**：注册或取消本程序的 Windows 登录启动项。
- **退出**：真正停止发送；关闭状态窗口只隐藏到托盘。

## 注意

自动发送的是新进入剪贴板的图片和文字，复制密码、验证码或其他敏感内容前请暂停或关闭文字同步。文字上限 64 KiB UTF-8 字节，超限会跳过，不截断；文件列表不发送。大图和长文字不保证三秒完成。程序不保存接收内容，但系统剪贴板历史、截图工具及笔记应用保存不受它控制。

配置在 `%LOCALAPPDATA%\ClipBridgeBLE`，不要删除或公开 `session.json`。iPad 剪贴板内容 10 分钟后过期，接收界面可点“重新复制最新内容”再次写入。已有用户见[文字同步升级说明](upgrade-v0.4.md)，遇到问题见[故障排查](troubleshooting.md)。
